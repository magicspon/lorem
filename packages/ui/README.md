# ui

The component library: shadcn's `base-maia` components built on [Base UI](https://base-ui.com) and
styled with StyleX.

## Exports

| Path                             | What it gives you                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `@repo/ui/<group>/<name>`        | One component and its parts, such as `@repo/ui/overlays/dialog`. A component with several parts is a namespace (`import * as Dialog from '@repo/ui/overlays/dialog'`, then `Dialog.Root`, `Dialog.Trigger`, `Dialog.RootProps`); one with a single part is a named export (`import { Button }`). The groups are `actions` (`button`, `button-group`, `icon-button`, `color-scheme-toggle`), `data-display` (`avatar`, `badge`, `dot`), `disclosure` (`accordion`, `collapse`, `tabs`), `effects` (`letter-glitch`, a WebGL 2 backdrop of glitching letters, and `scrambled-text`, text whose letters scramble near the pointer), `feedback` (`alert`, `progress`, `skeleton`, `toast`), `forms` (`field`, `fieldset`), `inputs` (`checkbox`, `input`, `input-group`, `radio-group`, `select`, `switch`, `textarea`, `toggle`, `toggle-group`), `layout` (`card`, `separator`, `stage`, a panel floating over content that fills the window), `overlays` (`alert-dialog`, `dialog`, `dropdown-menu`, `popover`, `tooltip`) and `typography` (`blockquote`, `code`, `heading`, `kbd`, `link`, `text`, `truncate`, `visually-hidden`, and `type-styles`). |
| `@repo/ui/layout`                | `Box`, `Flex`, `Stack`, `Grid`, `Container`, `Section`, `List` and `ListItem`: layout primitives whose props take `Space` steps and keyed values only. `display`, `direction`, `gap` and `columns` take a value per breakpoint (`Responsive`); `grow` and `shrink` place a primitive in a flex parent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `@repo/ui/styles/tokens.stylex`  | StyleX tokens: `colors`, `radii`, `space` (gap, padding, margin; type `Space`), `size` (other lengths; type `Size`), `fontSize` and `lineHeight` (the type scale, steps 1 to 9; type `FontSize`), `fonts`, `text`, `motion`. The `.stylex` ends the path so the compiler reads it as tokens.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `@repo/ui/styles/shadows.stylex` | StyleX tokens: `shadows`, every box shadow in the library (focus and invalid rings, popups, menus, card outlines, edge lines).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `@repo/ui/styles/<name>`         | `themes` (`lightTheme` and `darkTheme`, which override the system's scheme on a subtree), `animations`, `shared` (styles several parts use), `utilities`, and `sizing` (`width`, `height`, `maxWidth` by `size` step, to pass as `sx`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `@repo/ui/lib/sx`                | `styleProps`, `stateStyleProps` and the `Sx` types that every part's `sx` prop uses.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `@repo/ui/globals.css`           | The CSS reset and font. Import it once in the app.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## Commands

`pnpm storybook:ui` from the repo root. `pnpm test` runs every story as a browser test.
